# Golden mapping misses: sampling, pruning, and verification

This investigation starts from the saved 3-seed, cap-100, tolerance-1,
explicit-H, full one-edge-sweep benchmark. It does not replace its results
with reference-guided mappings or mix different search settings into one score.

## What is established

- All **137 nonempty misses** were inspected. Independent reconstruction in
  original RDF atom order agrees with the saved reference after removing map
  labels before stereochemistry assignment. There is no detected index-conversion
  error. All 165 complete-reference failures/unknowns conserve element identity
  in their reference pairs.
- **106/137** have no retained mapping with the reference's choice of source
  atoms, even modulo exact source endpoint automorphisms. **134/137** already
  fail the necessary source/target orbit-pair count check. The remaining three
  require the joint chemical-equivalence check, not independent atom orbits.
- Every retained target action inspected in these 137 is an exact chemical
  endpoint automorphism. Composing those actions cannot change the chemical
  equivalence class used for scoring. The evaluator's zero-symbolic-query
  shortcut was therefore valid for these archives; no unfinalized terminal
  symmetry groups were found.
- These checks describe the **saved families**, not a proof that every possible
  search trajectory or reference mapping survives finite seed/cap pruning.

## Confirmed sampling-limited cases

Of the **15 uncapped misses**, 30 ordinary seed orders recovered 13 at unchanged
tolerance 1 and cap 100. Case 1739 recovered with 100 orders. Case 1740 did not
recover with 100 blind orders, but a guided order proves it is representable
with the normal matcher, tolerance 1, cap 100, and one ordinary sweep cut.

Case 21 is a concrete source-choice failure. Its closest original candidate
maps the framework correctly but uses reactant O4 for product O5; the reference
uses water O13. The order visits O4 before O13, and no branch is retained that
declines O4 to reserve the position for O13. Thirty orders recover the reference
at order 11 of the `(1,2)` cut. This is not hidden target symmetry.

Case 1740 contains two N–N reference bond-order differences of 2. Tolerance 2
was tried only as a diagnostic and is **not a proposed fix or default**. More
importantly, tolerance 1 succeeds with cut `(8,9)` and the source seed prefix
`24,9,7,8`, followed by the remaining atoms. No atom mapping was imposed: the
matcher found the reference itself. This guided experiment proves reachability,
not blind recovery. The unsuccessful two-cut experiment is also retained.

Among four small capped nonempty cases, raising the cap from 100 to 1,000 with
the same three orders recovered none. Cases 602 and 1285 no longer hit that
higher cap and still missed. Thirty orders at cap 100 recovered cases 11 and
602. These controls separate seed-order effects from simply needing a larger cap.

## Five initially empty cases

All five histories ended through fragment-growth cap stops; the current wrapper
returns an empty fragment result on a cap and discards that descendant subtree.
If every available route does this, the final result has no terminal mapping.

At **30 orders and cap 100**, cases 745, 853, 1405 and 1654 recover the reference.
Case 1665 returns candidates but still misses at both 30 and 100 orders. It is
**unresolved**, not proven impossible. Cases 745 and 853 also recover with
three orders and cap 1,000; increasing the cap is not necessary for their recovery.

## The 23 verification unknowns

These originally exhausted the reference checker, not AAM search. Separate
diagnostic checks use the original archives:

1. Reject a family only if its mapped source-atom orbit counts cannot equal the
   reference. Target actions cannot change the source domain.
2. Optionally reject using target orbits generated by the union of all available
   actions and endpoint automorphisms. This deliberately overapproximates the
   allowed actions: failure is conclusive, passing is **not** acceptance.
3. Verify remaining correlated actions with the exact symbolic query. The
   original checker permits only 10 seconds per query, even when almost the
   entire 120-second case budget is still available. A diagnostic allows a query
   to use that remaining budget. Positive witnesses are independently executed
   and checked against the full reference certificate.

`verification23.csv` and `summary.json` give the final resolution counts. These
checks do not recompute top-1 or change the saved AAM search. A finite-bitvector
solver experiment was slower and is not enabled by default; its negative results
and source snapshot are retained rather than silently discarded.

Final resolution: **12 recovered, seven not recovered, four still unknown**
(905, 1033, 1351, 1758). On the unchanged original search results, this raises
the confirmed complete-reference family recovery from 1,595 to **1,607/1,760
(91.31%)**, with 149 misses and four unknowns. Top-1 is unchanged. The additional
seed/cap/guided probe successes are **not** included in this number.

## What is not yet established

**No case has been proved inherently unfixable.** We have demonstrated that
multiple misses are seed/order-sensitive, but cannot label every remaining
capped miss as mere bad luck. Most of the 122 capped nonempty misses have not
received the same controlled higher-seed rerun. Case 1740 remains a blind-search
failure under the tested tolerance-1 budgets; case 1665 also remains a miss.
Any still-unknown reference queries must not be counted as absent mappings.

The core limitation is that completing a seed order and all one-edge cuts is
not exhaustive over source choices and fragment decompositions. A matching
fragment is committed; skipping a usable source atom for a different later
donor is not automatically another branch. A regression test with complete
explicit-H methanol/water graphs reproduces this seed-order dependence.
