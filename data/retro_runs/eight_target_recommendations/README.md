# Eight-target recommendation results

Each target directory contains:

- `results.json`: compressed-domain precursor recommendations and sampled mapping witnesses.
- `viewer.html`: standalone interactive viewer.
- `postprocess_time.tsv`: merge and viewer-generation wall times.

The full inventory scan shards are intentionally excluded from Git. The
targets used for the run are recorded in `targets.tsv`.
