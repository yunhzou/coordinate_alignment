# Example 5: full-bank beta run

**Completed blind recommendation: 58/58 target atoms, including explicit H.**
No ground-truth reactants or mappings were supplied as search hints.

Bank: `merged_fast_delivery_with_inventory`, all **155,305** structures.
Target and exact configuration are in the run's `query_full/manifest.json`.
Tolerance 1.0, branch cap 100, all source seeds, no sweep, no hidden candidate
or reactant-count cap. The full workflow and core AAM are unchanged.

## Timing

- **20 min 54 sec end-to-end**, first scan allocation to final successful
  coordinator exit (Slurm 2026-09-06 02:34:21–02:55:15).
- This includes repeated cluster CONFIGURING/Cleaning failures, manual
  rescheduling, index construction, and a coordinator watchdog while waiting
  for four index jobs that had not started. It is not pure matching time or a
  clean steady-state throughput benchmark.
- Peak useful-job allocation: **1,920 CPUs across 34 nodes**. Allocated compute:
  **120.15 CPU-hours**, excluding cancelled jobs that never started; includes
  the waiting coordinator and successful recovery. These are allocated CPU
  hours, not measured utilization.
- Final replay from the saved queries/AAM: **26.712 s**, including the lazy
  recommendation search and final result writing within the coordinator.
  Four remaining indexes were finished first in the same 43-second recovery
  allocation. The replay is **not** a fresh full-bank runtime.
- Only two distinct sources received augmented AAM: **10.010 s** and
  **0.303 s**. Those results were reused after the watchdog and for repeated
  source copies; no completed AAM was rerun.

The earlier full workflow measured 27:25 for scan/persistence alone, without
assembly. Resource allocations differ, so this is not a controlled speedup
ratio. The beta now finishes recommendation within the measured time above.

atomwise matches. Counting explicit H, this set supplies **58 unique target
atoms from 175 input atoms**. This illustrates the cost of prioritizing fewer
distinct species ahead of retention; it is not evidence of chemical feasibility
or a globally optimal synthesis. It is not the literature ground-truth set.

per-copy injectivity, element identity, and every carried source bond against
the target at tolerance 1.0. The core matcher was not changed for this run.
