# Big-block beta smoke test: example 5

This is a **three-known-ingredient test**, not a blind full-bank benchmark.
The inputs are the three reactants and target in
`docs/example_runs/t05_ground_truth.json`. No desired atom mappings or reaction
rules were supplied to the beta workflow.

- Slurm job 432447: 4 allocated CPUs, 16 GB, ten-minute watchdog.
- Explicit hydrogen, tolerance 1.0, branch cap 100, all source seeds, no sweep.
- First fully refined recommendation: **58/58 target atoms covered**, using
  all three precursor structures, one copy each.
- Search including connected gap queries, selected-source augmentation,
  occupation processing, beta assembly, and checkpoint callbacks: **23.450 s**.
  This excludes CLI input preparation and final report/result writing.
- Three connected bank queries: full target, then gaps of 26 and 9 atoms.
- Nine source connected searches and three selected-source augmented searches.
- One augmented search hit its branch cap; this remains explicit in the result.
- Returned cover has **9 retained fragment units**. It is a heuristic first
  cover, not the minimum-fragment/global optimum certificate; the earlier
  dedicated known-set analysis found a 6-fragment cover.

Saved run directory:

```text

```

`manifest.json` records exact inputs/settings. `events.jsonl` references the
12 typed checkpoints. `result.pkl.gz` preserves complete selected mapping
evidence; `result.json` records each R mapping, target fragment regions, and
the empty uncovered-target list. All heavy atoms and H are represented.

This test establishes that the new scheduling path works on a full target;
it does not establish a large-bank speedup or chemical feasibility. The full
workflow and core AAM remain unchanged.
