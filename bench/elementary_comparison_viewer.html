Mapping provenance and interpretation

Both choices are actual saved mappings, not ground truth. Original XYZ coordinates and WBO connectivity are preserved; no SMILES conversion or new AAM search. Every atom including H is scored. Bond presence: WBO > 0.2; order-change threshold: 0.5. Single sticks depict connectivity, not integer bond order. Colored event overlays mark only existing edges on each endpoint. Identity colors, if enabled, identify source atoms—not fragments. The same r-index denotes the same input atom across both methods. Switching methods does not change geometry or relabel input atoms. Rotation is linked for comparison, not a new alignment calculation. Absence refers to saved families, not every possible search.
